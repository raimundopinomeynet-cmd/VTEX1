# Documentación del Blog VTEX IO

## Introducción

Este blog fue creado usando VTEX IO Store Framework con bloques nativos de VTEX.

## Características

- **Página de inicio del blog**: Muestra una lista de artículos publicados
- **Plantilla de artículo**: Diseño simple y limpio para el contenido
- **Responsive**: Se adapta a diferentes tamaños de pantalla
- **Personalizable**: Estilos CSS fáciles de modificar

## Bloques Utilizados

- `flex-layout`: Para la estructura y layout
- `rich-text`: Para el contenido de texto y títulos
- `link`: Para los enlaces entre páginas

## Limitaciones Actuales

- No incluye sistema de autor
- No incluye fechas de publicación
- No incluye categorías o etiquetas
- No incluye buscador
- Los artículos se gestionan manualmente mediante archivos JSON

## Mejoras Futuras Posibles

- Agregar componentes React personalizados
- Integrar con un CMS headless
- Agregar sistema de comentarios
- Implementar paginación
- Agregar filtros y búsqueda
